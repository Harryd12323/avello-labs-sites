# avello-labs-sites
Official website for Avello Labs: SEO, AEO, ongoing website care and custom web apps.

It's a static site (plain HTML, CSS and a little JavaScript) hosted from this repo, with no build step.

## Shared header, footer and head

Every page shares the same head tags, header/nav and footer. They live between marker comments
(`<!-- shared:head -->`, `<!-- shared:header -->`, `<!-- shared:footer -->`) and are generated by
`tools/site.py`. Edit the templates in that script, never the marked blocks in the pages.

From the repo root (Python 3, nothing to install):

```sh
# Re-apply the shared blocks to every page and rebuild sitemap.xml
python3 tools/site.py sync

# Start a new page (for example a blog post), then fill in its content
python3 tools/site.py new /blog/my-first-post/ "Post title | Avello Labs" "One-sentence meta description"
```

Page content, titles, meta descriptions, og tags and JSON-LD sit outside the markers and are never touched.

To go live, set `NOINDEX = False` in `tools/site.py` and run `sync`.

## Preview locally

```sh
python3 -m http.server 8000
```

Then open http://localhost:8000. Pages use root paths like `/assets/site.css`, so opening the HTML files directly won't load the styles.

## Contact form

The form on the home page sends through [Web3Forms](https://web3forms.com). Messages go to the email the access key was
created with. Paste the key into the `access_key` field in `index.html` (search for `PASTE YOUR WEB3FORMS ACCESS KEY`).
