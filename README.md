# avello-labs-sites
Official website for Avello Labs: SEO, AEO, ongoing website care and custom web apps.

It's a static site (plain HTML, CSS and a little JavaScript) hosted from this repo, with no build step.

## Shared header, footer and head

Every page shares the same head tags, header/nav and footer. They live between marker comments
(`<!-- shared:head -->`, `<!-- shared:header -->`, `<!-- shared:footer -->`) and are generated by
`scripts/site.py`. Edit the templates in that script, never the marked blocks in the pages.

From the repo root (Python 3, nothing to install):

```sh
# Re-apply the shared blocks to every page and rebuild sitemap.xml
python3 scripts/site.py sync

# Start a new page, then fill in its content
python3 scripts/site.py new /pricing/ "Page title | Avello Labs" "One-sentence meta description"
```

## Blog

Posts live in `blog/<slug>/index.html` and are hand-written like every other page. Each one starts as a draft:
drafts carry noindex, show a "Draft" label, and stay out of the sitemap and `blog/feed.xml`.

```sh
# Start a draft post (title, then meta description), then write it between the <article> tags
python3 scripts/site.py post /blog/my-post/ "Post headline" "One-sentence meta description"

# Publish it: sets today's date, adds it to the list, feed and sitemap, and turns on the footer link
python3 scripts/site.py publish /blog/my-post/

# Tests for the blog build (run on a throwaway copy of the site)
python3 scripts/test_site.py
```

Posts can also be written in a plain text format (header lines like `Title:` and `Keyword:`, then `##` headings,
lists, `Q:`/`A:` pairs and a `Call to action:` line; see `scripts/blogpost.py`). The blog agent drafts in it, and:

```sh
python3 scripts/site.py check-post post.txt     # every rule a post must pass (copy rules, keyword, links, FAQ...)
python3 scripts/site.py import-post post.txt    # build it as a draft page (with FAQ schema), if it passes
python3 scripts/site.py keywords                # the search keyword each page owns
python3 scripts/site.py check-keyword "..."     # the pages a new keyword would compete with
```

`sync` fills in each post's byline and reading time, its Article schema, the related links beside it and the
list on `/blog/`. While nothing is published, `/blog/` itself carries noindex and lists the drafts for review;
after that it lists published posts only. If a published post links to a draft in its text, `sync` prints a
warning. To change the publish or update date by hand, edit `article:published_time` or
`article:modified_time` in the post's head and run `sync`.

Page content, titles, meta descriptions, og tags and JSON-LD sit outside the markers and are never touched.

To go live, set `NOINDEX = False` in `scripts/site.py` and run `sync`.

## Problem pages and the homepage video

`/cant-find-us/`, `/no-calls/` and `/too-much-admin/` are built from the text files in `scripts/problems/` (format
in `scripts/problems.py`). Never edit their HTML. The homepage's three buttons and the footer's "Common problems"
links come from the same files.

```sh
python3 scripts/site.py problems    # check the copy rules, build the three pages, then sync
```

Videos play from YouTube's no-cookie player only after a click. Add a video with `Video:` and `Video-date:` in the
page's text file (or `WELCOME_VIDEO` in `scripts/site.py` for the homepage) and a 1280x720 thumbnail in
`assets/videos/`. Steps and scripts: `docs/video-scripts.md` (local only).

## Settings in scripts/site.py

- `PHONE`: the business phone number. Empty hides the header's tap-to-call button, the footer and contact
  section number and the phone in the structured data. Set it and run `sync`.
- `PRICE_FROM`: the starting price. Empty hides every "Packages starting at" line.
- `BLOG_AUTHOR_PERSON`: the name in post bylines.
- Homepage sections waiting for content (client quotes, "Who you'll work with") are in `index.html`, hidden, with
  instructions in the comment above each one.

## Removed pages and the not-found page

A removed page keeps its address as a small redirect page, so links to it still work: write one with
`redirect_page()` in `scripts/site.py` (see `blog/google-search-off-schools-ai/`). Redirect pages are skipped by
`sync` and left out of the sitemap, the blog list and the feed. `404.html` is the branded page GitHub Pages
shows for addresses that don't exist; `sync` keeps its header and footer current.

## Preview locally

```sh
python3 -m http.server 8000
```

Then open http://localhost:8000. Pages use root paths like `/assets/site.css`, so opening the HTML files directly won't load the styles.

## Contact form

The form on the home page sends through [Web3Forms](https://web3forms.com). Messages go to the email the access key was
created with (harris@avellolabs.com). The key is in the `access_key` field in `index.html`; it's public by design.
