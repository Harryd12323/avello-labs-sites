# Avello Labs brand assets

| File | Use |
| --- | --- |
| `icon.svg` | The mark on its own (transparent, 64×64 grid) |
| `logo-ring.svg` | Wordmark inside the partial ring. White text, transparent background, **dark backgrounds only** |
| `logo-horizontal-dark.svg` | Mark + wordmark for the site header on dark backgrounds (white text) |
| `logo-horizontal-light.svg` | Mark + wordmark on light backgrounds (navy text) |
| `favicon.svg` | Mark on a dark navy rounded square |
| `preview.html` | Every asset on dark and light backgrounds, large and tiny |

All text has been converted to outlined paths, so the SVGs don't need the font installed. Nothing in this folder embeds the reference PNGs.

## Typeface

**Montserrat** by Julieta Ulanovsky and the Montserrat Project Authors
(https://github.com/JulietaUla/Montserrat). It's licensed under the **SIL Open Font License 1.1** (https://openfontlicense.org).

- "Avello" is set in Montserrat **SemiBold (600)**. Its "A" is Montserrat's Greek capital lambda (Λ, U+039B), which gives the open, crossbarless A that echoes the mark.
- "Labs" is set in Montserrat **Light (300)**.

To set new text in the brand font, use Montserrat from Google Fonts. It is free for commercial use under the OFL.

## Colors

The brand is blue to cyan. There's no purple or indigo anywhere.

| Role | Hex |
| --- | --- |
| Brand blue (gradient start) | `#4D74F2` |
| Light blue (gradient middle) | `#62AFF9` |
| Cyan (gradient end, accent) | `#22D3EE` |
| Wordmark on dark | `#FFFFFF` |
| Wordmark on light / favicon tile (navy) | `#0A1022` |

The mark and the ring both use the same gradient, running from brand blue on the left, through light blue, to cyan on the right.

On the website, the same three colors drive the buttons, links and highlights, on a dark navy background (`#070A19`). Buttons use dark navy text (`#061325`) on the blue-to-cyan fill, because white text on `#4D74F2` falls short of the 4.5:1 contrast that accessibility guidelines require.

## Rebuilding the logos

The SVGs are generated by `build.py`, so colors and shapes stay consistent across every file. To change a color, edit `ICON_STOPS` or `RING_STOPS` at the top of the script, then run it with Python 3 and the `fonttools`, `uharfbuzz` and `Pillow` packages:

```sh
python3 brand/build.py <folder containing Montserrat-VF.ttf> brand
```

`Montserrat-VF.ttf` is Montserrat's variable font from the google/fonts repository (`ofl/montserrat/Montserrat[wght].ttf`), renamed.

## The mark

The mark is two bars, both leaning about 20° off vertical, standing on a flat shared baseline. The left bar's top is cut parallel to the right bar's inner edge, which leaves an even gap so the two bars read as an "A" without touching. Corners have a small, even rounding.
